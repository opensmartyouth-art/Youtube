## 언제 무엇을 보면 되나요?

전체 컨셉이 궁금할 때는 프로젝트 기준 문서를 확인합니다.
특정 앨범이나 곡 작업이 필요할 때는 해당 앨범 문서를 확인합니다.
새로운 곡을 추가하거나 수정할 때는 최신 발매 앨범(4집) 문서부터 확인한 후, 기준 문서와 일관성을 체크합니다.
