# Void Archive

> 영어권(미국) 타겟 AI 인스트루멘털 음악 유튜브 채널.
> 작업·공부·일상의 특정 상황에 맞춘 플레이리스트형 믹스 영상을 제작한다.

- **채널명:** Void Archive
- **핸들:** @void-archive
- **URL:** youtube.com/@void-archive
- **타겟:** 미국 중심 영어권 시청자
- **포맷:** 롱폼 플레이리스트 믹스 (약 20분 ~ 2시간) + 보조 쇼츠
- **툴체인:** Suno (음악) · Higgsfield / Midjourney (썸네일·쇼츠) · FL Studio · Premiere Pro

## 1. 채널 컨셉

"빈 공간의 리듬" — 조용한 공간에서 혼자 집중하는 순간을 위한 음악.
듣는 사람이 **자기 상황과 겹쳐 보이는 구체적인 장면**을 제목·설명·썸네일로 제시하고, 음악은 그 장면을 방해하지 않고 받쳐주는 역할을 한다.

**핵심 원칙**
- 음악보다 **상황(context)** 이 먼저다. "deep house mix"가 아니라 "the quiet office", "exam week"처럼 장면을 판다.
- 작업·공부 컨텍스트가 조회수가 가장 꾸준하다.
- 밝고 따뜻하고 고급스러운 톤. 어둡고 무거운 비주얼은 지양한다.

## 2. 장르 운영

| 장르 | 비중 | BPM | 주 컨텍스트 |
|---|---|---|---|
| **Deep House** | 메인 | 110 ~ 116 | 작업, 공부, 코딩, 재택 |
| **Downtempo** | 서브 | 75 ~ 90 | 감정, 상황 (전환기, 출퇴근, 무거운 날) |
| **Jazzy Hip-Hop** | 서브 | 82 ~ 87 | 창작, 리서치, 글쓰기, 계획 |
| **Lofi** | 서브 | 70 ~ 78 | 문제 해결, 새벽, 감정 |
| ~~Nudisco~~ | **제외** | — | 조회수 저조로 운영 중단 |

**기본 배치 비율 (12편 기준)**
- Deep House 8 (작업 6 + 상황 2)
- Downtempo 4 (감정 2 + 상황 2)

**곡 수 기준**
- 1편당 8 ~ 9곡 기본
- 2시간 편성 시 14곡

## 4. 제목 규칙

```
{소문자 상황 문장}. [{장르} for {구체적 용도}] // {길이}
```

**예시**
```
the quiet office. [deep house for solo work sessions] // 1 hour
exam week. [deep house for the hardest study sessions] // 2 hours
the end of something. [downtempo for transitions] // 1 hour
```

- 앞부분은 전부 소문자, 마침표로 끝나는 짧은 문장
- 대괄호 안에 장르 + 용도
- 기획 단계에서 A / B / C 3가지 후보를 만들어 A/B 테스트에 활용

```
[상황 묘사 문단 — 듣는 사람이 자기 상황이라고 느끼게]

[00:00] 01. 트랙명
[mm:ss] 02. 트랙명
...

🔁 on repeat ♾️ — [영상 총 길이]

🎧 Still here? Like the video — it helps more than you think.

🔔 Subscribe to stay within the rhythm of empty spaces.
Welcome to the archive.
→ youtube.com/@void-archive

© Void Archive. All rights reserved.
Mixed with Suno · FL Studio · Premiere Pro · Midjourney

#해시태그 (약 15개)
```

**작성 원칙**
- 첫 문단은 "You know the feeling…"처럼 구체적인 장면으로 시작한다.
- 누가, 언제, 어디서 들을지 여러 케이스를 제시해 공감 범위를 넓힌다.
- 타임스탬프는 반드시 실제 음원 길이로 계산한다 (추정값 금지).

**`🔁 on repeat ♾️ — [총 길이]`의 목적**
- 마지막 타임스탬프에 영상 총 길이를 걸어 반복 재생을 유도한다.
- 반복 재생은 시청 지속 시간과 완주 수를 늘려 알고리즘 노출에 유리하다.
- "계속 틀어놔도 된다"는 심리적 허가 역할도 한다.

## 7. Suno 프롬프트 규칙

**구조:** 공통 Base 1개 + 트랙별 프롬프트

**공통 Base 예시 (Deep House)**
```
melodic deep house, 114 bpm,
no vocals, no lyrics, instrumental only,
warm sub bass, steady minimal groove,
{컨텍스트} atmosphere,
organic textures, warm and focused,
clean mix
```

**트랙 설계 원칙**
- 01번 트랙은 영상의 첫인상 — 도입이 가장 매력적이어야 한다.
- 중간 트랙(보통 05번)에 가장 hypnotic한 곡을 배치한다.
- 후반부로 갈수록 BPM을 1 ~ 2씩 낮춰 자연스럽게 마무리한다.
- 마지막 트랙은 "single warm chord, fade to silence"로 닫는다.

**작성 포맷** — 트랙명은 블록 밖, 프롬프트만 복사 가능한 블록 안에 둔다.

## 9. 제작 워크플로우

```
1. 기획        장르·컨텍스트 결정 → 제목/설명/썸네일/Suno 프롬프트 작성
2. 노션 적재   기획 문서를 노션 DB 페이지로 생성
3. 음악 생성   Suno로 트랙 생성 → 로컬 폴더에 저장
4. 길이 측정   스캔 스크립트로 파일별 길이 측정
5. 타임스탬프  실제 길이로 계산 → 노션 설명란·트랙리스트 업데이트
6. 썸네일      Higgsfield / Midjourney로 A컷·B컷 생성
7. 편집·업로드 Premiere Pro 편집 → 유튜브 업로드 → A/B 테스트
```

**로컬 폴더 구조**
```
/Users/seong-keun/Desktop/void/{번호}/
  01 트랙명.m4a
  02 트랙명.m4a
  ...
```

**길이 측정 스크립트 (터미널)**
```bash
for f in "/Users/seong-keun/Desktop/void/{번호}"/*; do
  echo "$(basename "$f"): $(ffprobe -v quiet -show_entries format=duration -of csv=p=0 "$f")"
done
```
- 경로에 공백이 있으면 따옴표로 감싼다.
- 파일 확장자는 m4a / mp3 / wav 혼재 가능 → 와일드카드(`*`) 사용.
- 폴더 안 실제 파일 기준으로 트랙명과 순서를 확정한다. 빠진 번호는 제외하고 계산한다.
